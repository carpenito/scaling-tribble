## 👋 Page d'accueil

Une page d'accueil bien conçue est un bon point de départ pour accueillir les utilisateurs dans votre hub développeur. C'est la page que nous vous recommandons de personnaliser le plus.

Si vous utilisez uniquement la fonctionnalité Guides (également appelée Documentation), vous pouvez simplement diriger vos utilisateurs vers celle-ci sur la première page de votre [navigation du site](doc:site-navigation).

## Créer une page d'accueil

Lorsque vous accédez à l'onglet **Page d'accueil**, vous pouvez personnaliser des éléments tels que l'en-tête et le contenu du corps.

## En-tête

**Titre promotionnel**  
Il s'agit du texte de titre qui apparaît dans l'en-tête.

**Texte promotionnel**  
Il s'agit du texte qui s'affiche sous le titre promotionnel, mais qui reste visible dans l'en-tête.

**Contenu**  
Sous le titre et le texte promotionnels, vous aurez la possibilité d'afficher Rien, des Boutons, une Barre de recherche ou du HTML personnalisé. Le HTML personnalisé remplacera votre titre/texte promotionnel, gardez cela à l'esprit lors de l'édition.

## Corps

Vous disposez de nombreux modèles pour le contenu de votre corps et vous pouvez en ajouter plusieurs si vous souhaitez afficher plusieurs modèles sur votre page d'accueil.

**Liens importants**  
C'est l'option par défaut si vous ne sélectionnez aucune autre option. Elle affiche la documentation, les annonces et les forums.

<Callout icon="🚧" theme="warn">
  Si l'une de ces trois fonctionnalités est désactivée, vous ne devriez pas utiliser une page d'accueil, car elle redirigera vos utilisateurs vers une page 404.
</Callout>

**Catégories de documentation**  
Cela liste simplement toutes vos catégories avec des liens rapides vers les pages de documentation. Vous pouvez également choisir d'afficher la section de référence.

**Trois colonnes de texte, texte, texte + média**  
Celles-ci vous permettent d'ajouter vous-même le texte que vous souhaitez afficher et de télécharger une image.

**HTML personnalisé**  
Si aucune de ces options ne convient à vos besoins, vous pouvez toujours ajouter du HTML personnalisé pour obtenir exactement ce que vous souhaitez.

La page d'accueil peut être activée ou désactivée dans votre tableau de bord de projet sous **Apparence > Navigation du site**, et vous pouvez basculer la section Page d'accueil pour l'activer/désactiver.

> ❗️ Désactivation de la page d'accueil
>
> La page d'accueil est partagée entre toutes les versions. Si vous désactivez la page d'accueil, elle sera supprimée partout.
