# Présentation

Le menu déroulant Ask AI offre à vos utilisateurs une assistance intelligente directement au sein de votre hub de documentation. Cette fonctionnalité propose une suite d'outils et d'assistants alimentés par l'IA qui aident les utilisateurs à trouver rapidement des réponses, à comprendre des concepts complexes, à générer des exemples de code et à interagir avec votre documentation de manière plus significative — le tout sans quitter votre site de documentation.

En intégrant des capacités d'IA dans votre documentation, vous pouvez :

* Réduire la charge de support en permettant aux utilisateurs d'obtenir des réponses immédiates à leurs questions
* Aider les développeurs à comprendre des concepts d'API complexes grâce à des explications en langage naturel
* Offrir une expérience de documentation plus interactive et personnalisée

Le menu déroulant Ask AI apparaît sous la forme d'une icône de menu intuitive dans vos pages de guides, créant une extension transparente de votre documentation qui améliore la compréhension et la satisfaction des utilisateurs.

## Fonctionnement

Le menu déroulant Ask AI s'affiche sous la forme d'une icône de menu dans vos pages de guides. Lorsqu'on clique dessus, il révèle un menu d'outils et d'assistants IA que les utilisateurs peuvent exploiter pour enrichir leur expérience de la documentation.

Le menu déroulant inclut des connexions à des assistants IA sophistiqués qui analysent et comprennent le contenu de votre documentation, ainsi que des outils utilitaires qui aident les utilisateurs à intégrer le contenu généré par l'IA dans leur flux de travail.

## Premiers pas

#### ReadMe Refactored

1. Cliquez sur Paramètres IA (icône Étincelle) en haut à droite.
2. Activez **Activer le menu déroulant IA** sur **ON**.
3. Sélectionnez les outils IA à inclure.
4. Cliquez sur **Enregistrer**.

#### ReadMe Legacy

1. Accédez à **Configuration** > **Fonctionnalités IA**.
2. Activez **Activer le menu déroulant IA** sur **ON**.
3. Sélectionnez les outils IA à inclure.
4. Cliquez sur **Enregistrer**.

## Outils disponibles

* **Intégration ChatGPT** : Exploitez le puissant modèle de langage d'OpenAI, entraîné sur le contenu de votre documentation, pour répondre aux questions des utilisateurs, expliquer des concepts et générer des exemples de code spécifiques à votre API. Cet outil excelle dans la fourniture d'explications détaillées et de guides étape par étape basés sur votre documentation.

* **Intégration Claude** : Offrez aux utilisateurs l'accès à l'assistant IA conversationnel d'Anthropic, qui fournit des réponses nuancées et utiles aux questions relatives à votre documentation. Claude est particulièrement habile pour comprendre le contexte et fournir des explications réfléchies de concepts techniques complexes.

* **Microsoft Copilot** : Permettez à vos utilisateurs de tirer parti de l'assistant IA de Microsoft pour générer des exemples de code et des suggestions d'implémentation basés sur votre documentation. Cet outil combine la puissance de GPT-4 avec la vaste expertise en développement de Microsoft pour aider les développeurs à implémenter rapidement votre API dans leurs projets avec un code syntaxiquement correct et conforme aux meilleures pratiques.

* **Copier en Markdown** : Permettez aux utilisateurs de copier facilement le contenu de votre documentation au format Markdown, facilitant ainsi le collage dans d'autres outils IA, IDE ou documents tout en préservant la mise en forme.

* **Afficher en Markdown** : Permettez aux utilisateurs de voir la structure Markdown sous-jacente de vos pages de documentation, ce qui est particulièrement utile pour les développeurs qui souhaitent comprendre comment structurer un contenu similaire ou s'inspirer de votre style de documentation.

En mettant ces outils IA directement à disposition dans votre documentation, vous créez une expérience en libre-service plus interactive qui aide les utilisateurs à tirer le meilleur parti de votre API avec un minimum de friction.
