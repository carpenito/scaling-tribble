### Structure des URL

La structure des URL de votre site sera sous-domaine/docs/slug-de-page. Seuls le sous-domaine et le slug de page peuvent être modifiés. Les chemins docs et reference ne peuvent pas être changés.

<p class="blank-line" />

### Navigation supérieure

#### Navigation gauche et droite

Dans cette section, vous pouvez ajouter des liens vers différentes parties de votre documentation ainsi que des liens externes.

#### Lien du logo

Par défaut, le lien du logo pointe vers votre page d'accueil, mais vous pouvez également le définir sur l'URL de votre page principale depuis vos [paramètres du projet](doc:project-settings).

Par défaut, toutes les sections activées de la documentation apparaissent sous forme de liens dans la navigation. Cela peut être personnalisé pour regrouper toutes les sections dans un menu déroulant.

### Activer/Désactiver les sections

ReadMe offre de nombreuses fonctionnalités, mais toutes ne s'appliquent pas à chaque entreprise. Si vous souhaitez désactiver une section (ou la réactiver lorsque vous êtes prêt à l'utiliser), c'est très simple ! Activez/désactivez les sections sous **Apparence > Navigation du site**.

<Image align="center" alt="Disabling a section will remove it from the navigation bar and hide all its content from public view" border={true} caption="Disabling a section will remove it from the navigation bar and hide all its content from public view" src="https://files.readme.io/97cf63a-CleanShot_2022-10-15_at_09.14.142x.png" />

<p class="blank-line" />

> 📘 Remarque
>
> Les pages personnalisées ne peuvent pas être désactivées. Tant que vous n'avez aucune page personnalisée, elles n'apparaîtront nulle part, il n'y a donc rien à désactiver !
