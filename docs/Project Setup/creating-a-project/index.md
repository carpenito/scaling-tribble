## Créez votre projet 🎨

Commençons par l'essentiel – donnons un espace à votre documentation API :

1. Connectez-vous à votre compte ReadMe
2. Cliquez sur **Créer un nouveau projet**.
3. Donnez à votre projet un nom qui correspond à votre API.
4. Téléchargez votre logo (nous ferons notre magie pour correspondre aux couleurs de votre marque !).
5. Choisissez un sous-domaine adapté à votre marque (ex. : votreentreprise.readme.io).

<Callout icon="☝️" theme="default">
  Consultez notre documentation sur [la migration depuis une autre plateforme vers ReadMe](https://docs.readme.com/main/docs/migration-moving-your-docs-to-their-new-home).
</Callout>

## Naviguez dans votre tableau de bord 🧭

Prenez vos marques dans votre centre de commande :

1. **Aperçu du tableau de bord du projet**
   * Le tableau de bord est votre centre de contrôle pour toute votre documentation
   * Accédez à tous vos projets depuis ce hub central
   * Consultez les métriques du projet et l'activité récente en un coup d'œil

2. **Navigation rapide**
   * Utilisez la barre latérale gauche pour passer d'une section clé à l'autre
   * Accédez aux paramètres du projet, aux options d'apparence et bien plus encore
   * Basculez entre les modes édition et visualisation en un seul clic

3. **Paramètres du projet**
   * Personnalisez les détails du projet à tout moment depuis le menu des paramètres
   * Gérez l'accès et les permissions de l'équipe
   * Configurez les options d'intégration pour votre flux de travail

## Gérez votre profil 👤

Faites de ReadMe le vôtre avec un profil personnalisé :

1. **Configuration de votre profil**
   * Cliquez sur votre avatar dans le coin supérieur droit
   * Mettez à jour votre nom d'affichage et votre photo de profil
   * Ajoutez votre rôle et vos coordonnées

2. **Préférences du compte**
   * Définissez vos préférences de notification
   * Configurez l'authentification à deux facteurs pour une sécurité renforcée
   * Gérez vos clés API pour l'accès à ReadMe

3. **Collaboration en équipe**
   * Invitez des membres de l'équipe à contribuer
   * Attribuez des rôles et des permissions appropriés
   * Créez un flux de travail de documentation collaboratif

## Recherchez et organisez vos projets 🔍

Gardez tout à portée de main :

1. **Recherche de projets**
   * Utilisez la barre de recherche en haut du tableau de bord
   * Filtrez les projets par nom, statut ou équipe
   * Trouvez exactement ce dont vous avez besoin, quand vous en avez besoin

2. **Organisation des projets**
   * Classez les projets par priorité ou par catégorie
   * Utilisez des étiquettes pour regrouper les projets connexes
   * Archivez les projets terminés ou inactifs

3. **Changement rapide de projet**
   * Passez d'un projet à l'autre depuis le menu déroulant
   * Consultez les indicateurs de statut des projets en un coup d'œil
   * Accédez plus rapidement aux projets récents grâce au menu d'historique
