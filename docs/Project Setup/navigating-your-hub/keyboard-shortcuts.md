您可以在 **管理员仪表板** 和 **编辑模式** 中使用键盘快捷键，快速在 ReadMe 项目的各个面板和编辑器之间切换。

## 仪表板快捷键

在 **管理员仪表板** 中使用以下快捷键，可快速打开常用面板或切换模式：

| 快捷键 | 操作                                                                                     |
| :------- | :----------------------------------------------------------------------------------------- |
| Ctrl+1   | 切换到 <i aria-label="View Mode" class="fa-solid fa-eye" /> 查看模式                   |
| Ctrl+2   | 切换到 <i aria-label="Edit Mode" class="fa-solid fa-edit" /> 编辑模式                  |
| Ctrl+3   | 打开 <i aria-label="My Developers" class="fa-solid fa-users" /> 我的开发者              |
| Ctrl+,   | 打开 <i aria-label="Settings" class="fa-solid fa-cog" /> 设置面板                    |
| Ctrl+i   | 打开 <i aria-label="AI" class="fa-solid fa-sparkles" /> AI 面板                           |
| Ctrl+b   | 打开 <i aria-label="Versions" class="fa-solid fa-code-branch" /> 版本与分支面板 |

## 编辑模式快捷键

您可以从顶部导航栏进入 <i aria-label="Edit Mode" class="fa-solid fa-edit" /> 编辑模式，并使用以下快捷键直接跳转到特定部分进行编辑：

| 快捷键 | 操作                         |
| :------- | :----------------------------- |
| Alt+1    | 跳转到指南编辑器        |
| Alt+2    | 跳转到教程编辑器       |
| Alt+3    | 跳转到 API 参考编辑器 |
| Alt+4    | 跳转到更新日志编辑器     |
| Alt+5    | 跳转到自定义页面编辑器  |

<Callout icon="💡" theme="default">
  提示：键盘快捷键可能因操作系统而异。在 macOS 上，大多数快捷键请使用 Command（⌘）代替 Ctrl。
</Callout>
